# Кейс «Медикаменте»: архитектура защиты конфиденциальных данных

Медицинская компания «Медикаменте» ведёт учёт пациентов, медкарт и платежей вручную (Excel, сканы на общем диске, файловая 1С) и планирует пятикратный рост. Проект решает две бизнес-потребности: привести хранение и учёт конфиденциальных данных в соответствие с законодательством РФ (152-ФЗ, 323-ФЗ) и снизить риски утечек при масштабировании и автоматизации.

Исходный ландшафт As-Is: [project10-landscape.drawio](project10-landscape.drawio).

## Ключевые архитектурные решения

- **Единый контур privacy-сервисов** (IdP, Vault/KMS, каталог данных, аудит/SIEM, DLP): защита предоставляется всем системам по умолчанию, новые интеграции не требуют перевалидации.
- **Политики доступа привязаны к тегам данных** (`c0–c3`), а не к таблицам: RBAC для персонала, ABAC для клинических данных («лечащий врач») и самообслуживания пациентов («только свои данные»).
- **Аналитика только на обезличенных данных**: единственный вход в озеро данных — через движок классификации и псевдонимизации; неклассифицированное трактуется как c3 (default-deny).
- **Миграция без big bang**: Parallel run по доменам (записи → CRM → платежи → ЭМК) с автоматической сверкой и письменной точкой невозврата на каждом этапе.

Диаграммы выполнены в draw.io (C4-нотация) с PNG-экспортом; текстовые материалы — Markdown с Mermaid-диаграммами.
