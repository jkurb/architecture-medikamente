# Диаграммы потоков данных As-Is

Одна диаграмма на процесс. Нотация: прямоугольник — внешняя сущность, скруглённый блок — процесс, цилиндр — хранилище.

Общая характеристика всех потоков As-Is: передача без шифрования, хранилища без разграничения доступа (кроме доменной аутентификации), операции без аудита.

## P1. Запись пациента на приём

```mermaid
flowchart LR
    PAT[Пациент]
    REC(P1. Регистрация записи<br/>ресепшен, вручную)
    J[(Журнал записей<br/>Excel, общий диск)]
    K[(Контракты<br/>сканы PDF, общий диск)]
    DOC[Мед. специалист]

    PAT -- "Ф. И. О., дата рождения,<br/>телефон, e-mail — устно/по телефону" --> REC
    PAT -- "паспортные данные<br/>для договора" --> REC
    REC -- "запись в журнал" --> J
    REC -- "скан подписанного договора" --> K
    J -- "просмотр расписания" --> DOC
    J -- "напоминание о приёме<br/>по телефону" --> PAT
```

Операции: ручной ввод, чтение всеми сотрудниками, редактирование без версионирования.

## P2. Приём пациента и ведение медицинской карты

```mermaid
flowchart LR
    PAT[Пациент]
    VISIT(P2. Приём и оформление<br/>медицинской документации)
    CARD[(Медкарты<br/>Excel + сканы JPG/PDF,<br/>общий диск)]
    FORM[(Расширенные анкеты<br/>сканы, общий диск)]

    PAT -- "жалобы, анамнез,<br/>хронические заболевания" --> VISIT
    PAT -- "расширенная анкета:<br/>адрес, место работы/учёбы" --> VISIT
    VISIT -- "заключение, назначения<br/>(врачебная тайна)" --> CARD
    VISIT -- "скан анкеты" --> FORM
    CARD -- "чтение истории<br/>любым доменным пользователем" --> VISIT
```

Операции: сканирование, ручное заполнение Excel, чтение без ограничения по ролям.

## P3. Оплата услуг

```mermaid
flowchart LR
    PAT[Пациент]
    CASH(P3. Приём платежа<br/>кассир)
    KKM[ККМ]
    X[(Дублирующий учёт<br/>Excel, общий диск)]
    BUH[(1С:Бухгалтерия<br/>файловый режим)]
    ACC(P3.1. Процессинг платежей<br/>бухгалтерия)

    PAT -- "оплата, Ф. И. О.,<br/>ссылка на договор" --> CASH
    CASH -- "фискальная операция" --> KKM
    KKM -- "данные чека<br/>OLE поверх TCP/IP,<br/>без шифрования" --> BUH
    CASH -- "ручное дублирование платежа" --> X
    BUH -- "платёжные документы" --> ACC
    X -. "сверка вручную" .-> ACC
```

Операции: двойной ввод (Excel + 1С), передача по OLE без защиты канала.

## P4. Учёт анализов

```mermaid
flowchart LR
    PAT[Пациент]
    LAB[Лаборатория анализов<br/>внешняя]
    TAKE(P4. Забор биоматериала<br/>и оформление направления)
    RES(P4.1. Приём результатов<br/>вручную)
    SCAN[(Результаты анализов<br/>сканы PDF/JPG, общий диск)]
    DOC[Мед. специалист]

    PAT -- "биоматериал, Ф. И. О.,<br/>дата рождения" --> TAKE
    TAKE -- "направление с ПДн<br/>бумага / e-mail" --> LAB
    LAB -- "результаты<br/>бумага / e-mail без шифрования" --> RES
    RES -- "сканирование" --> SCAN
    SCAN -- "чтение" --> DOC
    DOC -- "интерпретация результатов" --> PAT
```

Операции: передача ПДн внешнему контрагенту по открытым каналам, ручное сканирование.

## P5. Бухгалтерия, кадры, зарплата

```mermaid
flowchart LR
    EMP[Сотрудник]
    HR(P5. Кадровый учёт,<br/>зарплата, налоги)
    BUH[(1С:Бухгалтерия<br/>файловый режим)]
    FNS[ФНС, СФР]
    BANK[Банк]

    EMP -- "паспорт, СНИЛС, ИНН,<br/>банковские реквизиты" --> HR
    HR -- "кадровые записи,<br/>начисления" --> BUH
    BUH -- "отчётность" --> FNS
    BUH -- "зарплатные реестры" --> BANK
```

Операции: ввод ПДн сотрудников, формирование отчётности; файлы БД 1С доступны на уровне файловой системы.

## P6. Учёт ТМЦ и закупки

```mermaid
flowchart LR
    SUP[Поставщик]
    WH(P6. Учёт ТМЦ и закупок<br/>склад)
    TIS[(1С:Торговля и склад<br/>файловый режим)]
    BUH[(1С:Бухгалтерия)]

    SUP -- "накладные, счета" --> WH
    WH -- "приход/расход ТМЦ" --> TIS
    TIS -- "проводки<br/>внутренняя интеграция 1С,<br/>состав данных не контролируется" --> BUH
```

Операции: ручной ввод первички, автоматический обмен между базами 1С без контроля состава данных.

## P7. Отчётность и аналитика

```mermaid
flowchart LR
    SRC[(Excel-файлы и 1С<br/>общий диск)]
    BA(P7. Построение отчётов<br/>бизнес-аналитик)
    LOCAL[(Локальные выгрузки<br/>Jupyter, CSV на рабочей станции)]
    MGMT[Руководство]

    SRC -- "выгрузка данных с ПДн<br/>без обезличивания" --> BA
    BA -- "промежуточные копии" --> LOCAL
    BA -- "P&L, ABC-анализ" --> MGMT
```

Операции: копирование «сырых» ПДн на локальную машину, обработка в Jupyter/Python вне контролируемого контура.
